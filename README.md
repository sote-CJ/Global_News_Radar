# 세계 뉴스 레이더 · 정적 샘플

`index.html`은 실제 로컬 프로그램에 저장된 기사를 내보낸 독립형 데모입니다.
Python 설치나 서버 실행 없이 열 수 있습니다. 파일 생성 시점과 기사·지표 수는 화면에 표시됩니다.

## 내 컴퓨터에서 열기

`index.html`을 더블클릭하여 Edge 또는 Chrome에서 여세요.
파일 하나에 화면과 데이터가 모두 들어 있으므로 인터넷 없이도 목록 조회·검색·필터·정렬을 사용할 수 있습니다.
원문 기사 링크를 열 때는 인터넷이 필요합니다.

## GitHub Pages에 올리기

1. GitHub에서 빈 저장소를 만드세요. 무료 개인 계정의 일반적인 GitHub Pages 배포에는 공개 저장소를 사용합니다.
2. 이 폴더 안의 `index.html`과 `.nojekyll`을 저장소의 최상위 경로에 업로드하고 커밋하세요.
   상위 폴더 자체를 넣지 말고 파일을 직접 넣어야 합니다. `.nojekyll`은 선택 사항이며 Jekyll 처리를 생략합니다.
3. 저장소 **Settings → Pages → Build and deployment**에서 **Deploy from a branch**를 선택하세요.
4. Branch를 **main**, Folder를 **/ (root)**로 선택한 뒤 저장하세요.
5. 배포가 완료되면 Pages에 표시된 `https://사용자명.github.io/저장소명/` 주소로 접속하세요.

`README.md`는 업로드해도 되지만 웹 화면 실행에 필수는 아닙니다.
실제 프로그램 폴더, SQLite DB, 개인 설정, 로그, `.venv`는 업로드할 필요가 없습니다.
공개 페이지에 올리면 이 HTML에 담긴 기사 메타데이터와 지표는 방문자가 내려받을 수 있습니다.

## 데모 기능과 범위

- 저장된 전체 기사 목록, 분야·지역·검색·언어 필터, 중요도·최신순 정렬, 페이지 이동
- 원본 프로그램의 중요도 점수·이유·연관 기사 군집 표시
- 이 브라우저에만 저장하는 읽음 체크. 원본 DB나 다른 방문자의 상태와 연동되지 않습니다.
- 저장된 경제 지표 및 관심 종목 브리핑, 각 결과의 기준일·확인 시각·출처 표시
- 원본 DB에 수동 번역이 저장된 경우 번역 표시, 나머지 해외 기사는 원문 표시

새 정보 수집, 실시간 갱신, 재분석, 자동 번역, 기사 삭제, 설정 수정, Windows 알림은 실행하지 않습니다.
읽음 상태는 같은 파일을 같은 브라우저·주소에서 열 때 유지됩니다. 브라우저의 파일 URL 저장 제한이나 비공개 모드에서는 저장되지 않을 수 있습니다.
외부 폰트·CDN·분석 도구·데이터 API에 자동으로 접속하지 않으며, 원문 링크를 클릭했을 때만 제공처 페이지를 엽니다.
화면의 중요도는 프로그램의 규칙 기반 분석값이며, 경제 지표 설명은 일반적 설명입니다.
기사와 데이터의 권리는 각 권리자에게 있으며 공개 게시 시 제공처의 이용 조건을 확인하세요.
